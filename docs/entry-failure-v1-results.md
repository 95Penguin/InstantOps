# 本地入口业务退化实验 v1

日期：2026-10-29。模型保持两层GCN-GRU，Mac MPS训练5个epoch，seed=42。
按验证损失选择第4轮权重。此次实验为下一分钟故障状态预测，包括持续故障，
不是故障起点提前预警，也不是论文原结果复现。

## 可用于正文的定义

基于入口请求错误率定义业务退化：每分钟至少观测到20个入口请求，且错误率
不低于50%的状态连续持续至少2分钟。历史观测用于预测下一分钟的退化状态。

标签来自已完成登录入口请求的5xx比例。无充分观测为未知；离线事件起点回溯到
首分钟，在线确认需第二分钟结束。该阈值是探索性实验约定，并非已验证的业务SLO。
本次数据已用于探索定义，后续正式研究需冻结协议并进行独立验证。

## 数据和切分

- 160个候选事件，1,403个故障分钟。
- 34,278个可用窗口，边界隔离再剔除12个窗口。
- 训练/验证/测试窗口：23,993 / 5,136 / 5,137。
- 正样本：1,024 / 87 / 177。
- 固定时间顺序70/15/15；跨界事件整体排除，历史及标签确认窗口不跨分区。
  本次没有事件跨界，边界窗口剔除数为1 / 6 / 5。

## 测试结果

|方法|Precision|Recall|F1|AP|
|---|---:|---:|---:|---:|
|GCN-GRU，5轮选最佳|0.6722|0.9153|0.7751|0.7521|
|当前分钟错误率阈值规则|0.7656|0.8305|0.7967|0.6417|

模型评估5,137个窗口；规则仅评估当前请求数>=20的5,136个窗口，二者均有177个
阳性。规则AP基于二值输出，不等价于连续概率排序能力的全面比较。
规则F1较强表明故障持续性是重要信号。本轮不能据此声称提前预警或模型全面优于基线。
也不能与旧注入开始标签的分数直接比较。

## 根因监督限制

持续时间超过3600秒的3条注入记录被标为待核实，未擅自截断。与它们重合的失败
窗口保留预测标签，但根因未知、不参与节点监督。其余活动注入只提供候选根因。
本轮测试期177个故障窗口均无可评估根因标签，RCA指标为null，排名文件仍然导出。
必须核实日志持续时间或寻找其他根因证据，才能报告有效的联合定位成绩。
